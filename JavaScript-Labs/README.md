## Mục tiêu

Thực hành JavaScript từ nền tảng ngôn ngữ đến DOM, sự kiện, jQuery và GET; liên hệ với dữ liệu sản phẩm, tính tổng giỏ hàng và kiểm tra biểu mẫu trong ứng dụng TMĐT.

Mỗi Lab có index.html, PDF gốc, các trang walkthrough, thư mục js/css và tài nguyên khởi đầu. Không thay đổi bài cũ trong VeNha.

## Truy cập

Mở index.html bằng Live Preview/Live Server. Nếu dùng cổng 3000 như trong quá trình chạy thử, truy cập:

http://127.0.0.1:3000/JavaScript-Labs/index.html

Từ portfolio chọn Lab08, Lab09 hoặc Lab10, sau đó chọn Exercise. Đối chiếu PDF gốc của từng Lab để thử các trạng thái, lỗi minh họa và chụp minh chứng.

Portfolio dùng HTML/CSS thuần và ảnh cục bộ, không cần tải font hoặc thư viện từ CDN. Một số trang Lab dùng Bootstrap/Font Awesome qua CDN; jQuery có fallback cục bộ.
